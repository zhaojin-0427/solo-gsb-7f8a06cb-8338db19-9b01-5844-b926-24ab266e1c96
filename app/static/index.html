EPUB3 章节跳转修复（本地工具）

上传未加密 EPUB，修复失效的篇内锚点与 XHTML 相对链接；外部链接不动，字节级精确改写。

1. 选择 EPUB

限制：ZIP ≤ 20 MB；解压总计 ≤ 50 MB；XHTML ≤ 30 篇；不支持加密（META-INF/encryption.xml）EPUB。

包结构错误 / 无法继续

    2. 为失效链接选择新目标

    空 id 选项 = 章节顶部；目标列表仅含 manifest 内 XHTML 的 id。无法定位到原文字节的链接以红色标记，禁止导出。
    # 来源 链接文字 原 href / 失效原因 新目标与预览

    3. 导出

    导出时会再次扫描成品；只要仍有失效跳转（包括未裁决项），服务器就会拒绝下载。
